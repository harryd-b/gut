**STEP 0 — VERDICT: CORRECT** (with one presentational proviso: fact (ii) is asserted, not proved; the assertion is true and I supply the proof below).

(a) *Tensor identification.* P ⊗̄ (L∞(X)⋊Γ) ≅ (P⊗̄L∞(X)) ⋊_{id⊗α} Γ holds for any W*-dynamical system with Γ discrete, any type, no trace or invariant measure needed. Proof: the crossed product of (Q, Γ, α) is representation-independent (defined as the vN algebra generated by π(Q) and λ_Γ on K⊗ℓ²Γ, π(q)(ξ⊗δ_g) = (α_{g⁻¹}(q)ξ)⊗δ_g, λ_γ(ξ⊗δ_g) = ξ⊗δ_{γg}, independent of the faithful normal representation of Q on K). Realize both sides on H_P ⊗ L²(X,ν) ⊗ ℓ²Γ (ν ~ μ): the generators P⊗1⊗1, 1⊗π₀(L∞), 1⊗λ_γ of the left side coincide with π̃(P⊗̄L∞) ∪ λ̃_Γ of the right side under the obvious flip, using that π̃ is normal so π̃(P ⊗̄ L∞) = (π̃(P⊗1) ∪ π̃(1⊗L∞))''. Note the nonsingular-action unitaries carrying Radon–Nikodym corrections implement α on L² but play no role in the algebraic identification.

(b) *Canonical E.* For Γ discrete and any Q, the diagonal-corner map exists: with p_g := 1_K ⊗ e_{gg}, the (g,g) block of x ∈ Q⋊Γ equals π_g(E(x)) where E is defined by the (e,e) corner; one checks on the σ-weakly dense span of {qλ_γ} that E(qλ_γ) = δ_{γ,e}q, E is normal (compression), Q-bimodular (immediate on generators, extends by normality and separate σ-weak continuity of multiplication), and faithful: if x ≥ 0 and E(x) = 0, then every diagonal block p_g x p_g = π_g(E(x)) ⊗ e_{gg} = 0, and a positive operator with vanishing diagonal blocks is 0. No trace is used anywhere; type is irrelevant. Under the identification in (a), E = id_P ⊗ E_N, consistent with the stated formula.

(c) *Coefficient determination (ii).* This is the only assertion in Step 0 whose proof is nontrivial and is omitted. It is true; here is the clean argument, valid in all types. Suppose x_γ := E(xλ_γ*) = 0 for all γ. By bimodularity, for any finite sum y = Σ λ_{γ_i} q_i one has E(xy) = Σ E(xλ_{γ_i})q_i = Σ x_{γ_i⁻¹} q_i = 0 (note E(xλ_γ) = x_{γ⁻¹}). By Kaplansky density applied to the σ-weakly dense *-subalgebra of finite sums, choose a bounded net y_i → x* σ-strongly. Left multiplication by the fixed element x is σ-weakly continuous, and E is normal, so E(xx*) = lim E(x y_i) = 0; faithfulness of E gives xx* = 0, x = 0. (The "λ_γ-translates of L²(Q)" route also works: take φ a faithful normal state on Q — Q has separable predual here — set ψ = φ∘E; then {λ_γ L²(Q,φ)}_γ are mutually orthogonal with dense span in L²(M,ψ), and the γ-component of xΩ_ψ is controlled by the Fourier coefficients. But the Kaplansky argument above is shorter and avoids choosing φ.)

(d) *Conventions.* x_γ := E(xλ_γ*) is used consistently. On x = qλ_g it gives x_γ = δ_{g,γ}q, matching E(qλ_γ) = δ_{γ,e}q. The alternative convention E(λ_γ*x) would produce α-twisted modularity formulas; the proof never mixes the two. No breakage. Sanity check: u = λ_g gives u_γ = δ_{γ,g}·1, S_g = X, T = g — consistent through Steps 2–5 with no inverse mismatch (verified below).

**STEP 1 — VERDICT: CORRECT.**

Three sub-points, all fine:
- *Normality*: not actually a hypothesis to check — every *-automorphism of a von Neumann algebra is automatically normal (it is an order isomorphism, hence preserves bounded suprema). So "normal automorphism" is redundant but harmless.
- *Point realization*: β restricts to an automorphism of the projection lattice = the measure algebra of (X,μ); since (X,μ) is standard, von Neumann–Mackey point realization gives a Borel map T with β(a) = a∘T⁻¹ a.e., unique mod null (standard spaces are countably separated, which gives uniqueness). Standardness is genuinely needed — this is where the hypothesis is consumed; the result fails for general measure algebras.
- *Invertibility*: not automatic from a single point map, but it is here: β⁻¹ is realized by some Borel S, and the compositions realize the identity, so T∘S = S∘T = id off a null set; discard that null set to get a nonsingular invertible transformation. Nonsingularity is forced because β maps null projections to null projections (it maps 0 to 0 and is a lattice isomorphism).

**STEP 2 — VERDICT: CORRECT.** Both computations verified in detail.

*Left modularity*: 1⊗β(a) ∈ Q, so [(1⊗β(a))u]_γ = E((1⊗β(a))uλ_γ*) = (1⊗β(a))u_γ. Exact, no issue.

*Commutation identity*: with the stated convention λ_γ(1⊗a)λ_γ* = 1⊗γ_*a (γ_*a = a∘γ⁻¹, a left action, correctly a homomorphism), compute λ_γ*(1⊗γ_*a) = λ_γ*(1⊗γ_*a)λ_γ·λ_γ* = (1⊗(γ⁻¹)_*γ_*a)λ_γ* = (1⊗a)λ_γ*. The identity as written is exactly right.

*Right modularity*: [u(1⊗a)]_γ = E(uλ_γ*(1⊗γ_*a)) = u_γ(1⊗γ_*a). Correct.

*Inverse-error audit* (the classic trap): the derived equation (1⊗a∘T⁻¹)u_γ = u_γ(1⊗a∘γ⁻¹) leads via Step 3 to T⁻¹ = γ⁻¹ on S_γ. Cross-check against u = λ_g: there β(a) = g_*a so T = g, and the equation reads (1⊗g_*a)δ_{γ,g} = δ_{γ,g}(1⊗γ_*a) — an identity precisely when γ = g, i.e., T⁻¹ = g⁻¹ on S_g = X. No sign/inverse error. Moreover, even if a γ ↔ γ⁻¹ relabeling had occurred, the conclusion would be unharmed: Γ is a group, γ⁻¹x ∈ Γx either way, and R_Γ is symmetric — such an error could only relabel which group element realizes T⁻¹ on each piece, never move graph(T⁻¹) out of R_Γ.

*Centrality*: 1⊗a with a ∈ L∞(X) lies in ℂ1_P ⊗ L∞(X) ⊂ Z(P)⊗̄L∞(X) = Z(Q). So both sides commute past u_γ and the equation collapses to (a∘γ⁻¹ − a∘T⁻¹)·u_γ = 0. Correct.

**STEP 3 — VERDICT: GAP (real but trivially repairable), plus one sub-point that survives scrutiny.**

(a) *The genuine gap: "generating the Borel σ-algebra mod null" does not imply point separation.* The argument needs: γ⁻¹x and T⁻¹x unseparated by 𝒜 ⇒ γ⁻¹x = T⁻¹x. A countable algebra that merely generates Borel mod μ-null can fail to separate points on a non-null set of relevant pairs. Counterexample scheme: take C ⊂ X of positive measure and an injective Borel f: C → X with f(C) null and disjoint from C; for any countable generating algebra 𝒜₀, replace each Z ∈ 𝒜₀ by its ~-saturation under x ~ f(x) (x ∈ C). Saturation changes each Z by a subset of the null set f(C) ∪ (f⁻¹-corrections), images of Borel sets under injective Borel maps are Borel, so the saturated algebra still generates Borel mod null — yet it separates no pair (x, f(x)), x ∈ C, a positive-measure family of pairs. If T⁻¹x and γ⁻¹x happened to form such pairs, Step 3's conclusion would fail with that 𝒜. So the step as written is not a proof.

*Repair (one line)*: X is standard Borel, hence countably separated; choose 𝒜 to be a countable point-separating algebra (e.g., pull back the dyadic clopen algebra under a Borel isomorphism X ≅ a subset of {0,1}^ℕ). Then "unseparated ⇒ equal" holds by definition, and the rest of the bookkeeping is untouched. With this choice the mod-null generation property is not even needed.

(b) *Null-set bookkeeping and representatives of scalar functions*: sound. For each Z ∈ 𝒜 fix a Borel representative; a∘γ⁻¹ and a∘T⁻¹ computed pointwise from these representatives represent the correct L∞ classes because γ and T are nonsingular (a null perturbation of χ_Z pulls back to a null set). Countably many Z, countably many conull sets, one intersection: valid. "T⁻¹ = γ⁻¹ a.e. on S_γ" follows.

(c) *Is "u_γ(x) ≠ 0" legitimate for nonabelian P?* Yes, given the hypothesis that P has separable predual — and this is exactly where that hypothesis is consumed. Q = P⊗̄L∞(X) ≅ L∞(X, P) as weak-*-measurable essentially bounded P-valued function classes (constant field direct integral; P_* separable makes the measurable-field theory work). For a representative, x ↦ ‖u_γ(x)‖ is measurable (sup of x ↦ |⟨u_γ(x), φ_n⟩| over a countable dense set {φ_n} in the predual ball), so S_γ = {‖u_γ(·)‖ > 0} is measurable and independent of representative mod null. Multiplication by the central scalar function is pointwise in this picture, and pointwise (scalar)·(element of P) = 0 forces scalar = 0 wherever u_γ(x) ≠ 0. All legitimate.

*However*, the pointwise apparatus is avoidable, which both simplifies and strengthens: let z_γ ∈ L∞(X) be the smallest projection with (1⊗z_γ)u_γ = u_γ (support of u_γ over the center subalgebra ℂ⊗L∞(X); exists by a standard lattice argument). From f·u_γ = 0 (f = a∘γ⁻¹ − a∘T⁻¹ central scalar) one gets χ_{|f|>ε}·u_γ = (χ_{|f|>ε}·f⁻¹restricted)·f·u_γ = 0 for every ε, hence supp(f) ≤ 1 − z_γ, i.e., f = 0 on S_γ := supp z_γ. This never evaluates u_γ at a point, and consequently *separability of P_* is not needed anywhere in the proof* (Steps 0, 4, 5 never used it either). The hypothesis can be dropped.

(d) *Scalar-centrality claim*: holds, as verified in Step 2 — ℂ1⊗L∞(X) ⊂ Z(Q). (Note it would fail for L∞(X)-valued but non-scalar central elements if P were replaced by a fiberwise-varying bundle; not the case here.)

**STEP 4 — VERDICT: CORRECT.**

- u_γ = 0 a.e. on Y for every γ: Y avoids every S_γ; for each fixed γ this holds off a null set, and Γ is countable, so a single conull set works for all γ simultaneously. (Countability of Γ is genuinely consumed here — a hypothesis, present.)
- [(1⊗χ_Y)u]_γ = (1⊗χ_Y)u_γ: this is left Q-modularity of E applied once, E((1⊗χ_Y)uλ_γ*) = (1⊗χ_Y)E(uλ_γ*). A single algebraic identity — no series, no convergence, nothing hidden. (Convergence enters only inside the proof of coefficient determination, where it is handled by Kaplansky + normality as in Step 0(c).)
- (1⊗χ_Y)u = 0 ⇒ 1⊗χ_Y = (1⊗χ_Y)uu* = 0 ⇒ μ(Y) = 0. Correct. In the central-support reformulation of Step 3, this reads 1 − ⋁_γ z_γ = 0, same content.

**STEP 5 — VERDICT: CORRECT.**

⋃_γ S_γ conull (Step 4) and T⁻¹ = γ⁻¹ a.e. on S_γ (Step 3, countably many exceptional null sets) give: for a.e. x, T⁻¹x ∈ Γx, i.e., (x, T⁻¹x) ∈ R_Γ a.e., i.e., T⁻¹ ∈ [R_Γ] under the stated definition. Then T ∈ [R_Γ]: since T is nonsingular and invertible, y ↦ Ty over the conull set {y = T⁻¹x} satisfies (Ty, y) ∈ R_Γ a.e., and symmetry of R_Γ gives (y, Ty) ∈ R_Γ a.e. (Equivalently: [R_Γ] is a group.) Overlaps S_γ ∩ S_δ cause no inconsistency: on the overlap both γ⁻¹x and δ⁻¹x equal T⁻¹x. Uniqueness mod null was already secured in Step 1.

**OVERALL VERDICT: LEMMA TRUE; PROOF CORRECT AFTER ONE REPAIR.**

The single defect is Step 3(a): "countable algebra generating the Borel σ-algebra mod null" must be replaced by "countable point-separating algebra" (available since X is standard Borel; separation then does all the work and mod-null generation is unnecessary). Everything else checks out line by line. Fact (ii) of Step 0 is asserted without proof but is true in full generality (proof supplied above).

*Genuineness of the claimed generality*: yes.
- Arbitrary type / no trace: genuinely fine; the canonical faithful normal E exists for any crossed product by a discrete group (diagonal-corner construction), and no step invokes a trace, modular theory, or L²-orthogonality beyond what E provides.
- No freeness/ergodicity: genuinely unused. Without freeness A is not maximal abelian and the realizing γ is not unique (see Remark (b)), but the lemma only asserts existence of T, which survives.
- Arbitrary P: the stated hypothesis "separable predual" is consumed only by the pointwise formulation of Step 3 and can be removed entirely via the central-support reformulation in Step 3(c). Γ countable and (X,μ) standard are genuinely needed (Step 4 and Steps 1/3 respectively) and are hypotheses.

**Strongest correct version.** Let (X,μ) be a standard probability space, Γ a countable group acting nonsingularly on X, N = L∞(X)⋊Γ (any type), P *any* von Neumann algebra (no separability of P_* needed), M = P⊗̄N, A = 1⊗L∞(X). If u ∈ U(M) satisfies uAu* = A, then the induced automorphism β of L∞(X) is β(a) = a∘T⁻¹ for a nonsingular invertible T, unique mod null, with T ∈ [R_Γ]. Moreover the proof yields the finer structural statement: with z_γ the central-L∞(X)-support of u_γ = E(uλ_γ*), the sets S_γ = supp z_γ cover X mod null and T⁻¹ = γ⁻¹ a.e. on S_γ.

**Remark (a)** — P = ℂ recovering one direction of Feldman–Moore: correct with a precise reading. For P = ℂ the lemma says: every unitary in L∞(X)⋊Γ normalizing L∞(X) induces an automorphism lying in [R_Γ]. That is the "automorphism part" (one direction) of the Feldman–Moore normalizer picture. It is *not* the full FM statement — the decomposition u = a·u_T (a ∈ U(A), u_T implementing T) requires the Cartan setting, i.e., essential freeness, which this lemma deliberately does not assume. As a one-direction recovery, the remark stands, and note the lemma is slightly more general than the FM context since freeness is dropped.

**Remark (b)** — a.e. uniqueness of γ under essential freeness: correct. If x ∈ S_γ ∩ S_δ on a positive-measure set, then γ⁻¹x = T⁻¹x = δ⁻¹x there, so δγ⁻¹ fixes the positive-measure set γ(·) pointwise; essential freeness forces δ = γ. Hence the S_γ are a.e. pairwise disjoint and the realizing γ is a.e. unique on its domain. Without freeness this fails badly (trivial action: T = id is realized by every γ ∈ Γ wherever u_γ ≠ 0), which is why the general lemma asserts only existence.
