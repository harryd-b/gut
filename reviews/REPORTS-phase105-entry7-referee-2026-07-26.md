**7. §5 dissolution — VERDICT: (i) CORRECT; (ii) WRONG AS STATED, CORRECT WITH REPAIR; overall CORRECT WITH REPAIR.** (Adjudication E.)

(i) Unitarity is correct: the homogeneous H^{1/2} seminorm 2πΣk|f̂_k|² equals the Dirichlet energy of the harmonic extension (Douglas identity), which is conformally invariant; disk Möbius maps are conformal automorphisms, so the action on H^{1/2}/constants is unitary. (ii) **This is the real error in the derivation.** Invariance of the profile *class* mod constants means η∘g = η + c_g for constants c_g, and g ↦ c_g is an additive character c: Γ → ℝ. The stated inference "ergodic ⇒ invariant class a.e. constant ⇒ zero" is only valid when c ≡ 0; nothing in the text rules out c ≠ 0, and nonzero characters *exist* in abundance here (Γᵃᵇ = ℤ² for the punctured torus). Calling the missing step "measurable bookkeeping routine but unspelled" (GAP-6) mislabels a genuine ergodic-cocycle rigidity question. **Repair (and honest answer to whether measurable η with c ≠ 0 exists):** set F(x,y) = η(x) − η(y) on S¹×S¹; the characters cancel, so F is invariant under the diagonal Γ-action. By Hopf's argument, for divergence-type Fuchsian groups (equivalently: ergodic geodesic flow) the diagonal action on S¹×S¹ is Lebesgue-ergodic, so F is a.e. constant, and antisymmetry F(x,y) = −F(y,x) forces the constant to be 0; Fubini gives η a.e. constant, hence c ≡ 0. So *no* measurable solution with nonzero character exists for divergence-type groups — which includes all lattices, in particular §6's group — and the dissolution conclusion stands there. Two caveats must be recorded: (a) the citation "first-kind Fuchsian groups act ergodically on ∂ℍ [Hopf]" is imprecise — Hopf's theorem is about divergence type, and mere first-kind (infinitely generated, convergence-type) does not obviously supply even single ergodicity, let alone the double ergodicity the repaired argument needs; the correct scope is divergence type. (b) Single ergodicity on S¹ would in any case be insufficient; the repair genuinely needs S¹×S¹.
