# Referee Report: "φ = ω∘α is not in the exact unitary orbit of ω"

**Summary.** The theorem survives. I attacked every step analytically and ran the mandated numerics; the argument is sound, and its one genuinely fragile point — the relative sign between the cocycle's spectral flow and the modular conjugation flow in Step 5, which if wrong would make ℓ ≡ 0 and kill the proof — checks out because both flows are the *same* one-parameter unitary u_t by the chain rule. However, Step 5 as submitted contains two real errors: the claimed pointwise asymptotic |η̂|² ~ (D/2π)ν⁻² does not follow from linear growth (Tauberian gap), and the dyadic-shell arithmetic ("mass ~ D/2π constant per shell, need N shells") is simply wrong — the per-shell mass is ~D/(4πε), *divergent* per shell (the submitted arithmetic is correct for a ν⁻¹ density, i.e. the logarithmic-growth case, not the linear one). Both errors are repairable and the repair *strengthens* the theorem: only η̂ ∉ L² near ν = 0 is needed, which is equivalent to the refereed weaker fact sup_t‖k_t‖ = ∞. Verdict: **CORRECT WITH REPAIR** overall.

## (A) Prop 1 and the naive-route refutation — CORRECT

Bookkeeping verified: σ_t(u)b′Ω = b′Δ^{it}uΩ (u ∈ A commutes with b′ ∈ A′ = A(I′) by Haag duality); Δ^{it}uΩ ⇀ ω(u)Ω needs the *Fock* generator a.c. on Ω^⊥, which follows from G1 since the n-particle generator is a sum of commuting a.c. one-particle generators (sums of independent a.c. spectral measures are a.c.). Uniform bound ‖σ_t(u)‖ = ‖u‖ plus density on both slots gives WOT. The WOT-nullity of W(k_t): ⟨W(g)Ω, W(k_t)W(h)Ω⟩ = (unimodular Weyl/Fock phase)·e^{−‖k_t+h−g‖²/4}; the phase involves only Im⟨·,·⟩ terms of modulus 1, so |matrix element| ≤ e^{−(‖k_t‖−‖h−g‖)²/4} → 0. So both the honest coboundaries u*σ_t(u) (with ω(u) = 0) and the actual cocycle W(k_t) are WOT-null: weak decay indeed cannot separate them. The refutation of the naive route stands.

## (B) Step 1 — CORRECT

φ = ω(u·u*) ⟹ c_t := (Dφ:Dω)_t = u*σ_t(u): chain rule checks, c_tσ_t(c_s) = u*σ_t(u)σ_t(u*)σ_{t+s}(u) = c_{t+s}, and Ad(c_t)∘σ^ω_t = Ad(u*)σ_tAd(u) = σ^φ_t. Fixed vector: V_tξ = c_tΔ^{it}u*Ω = c_tσ_t(u*)Ω = u*σ_t(uu*)Ω = ξ, using Δ^{it}Ω = Ω. Group law V_tV_s = c_tσ_t(c_s)Δ^{i(t+s)} = V_{t+s} follows from the chain rule (V_t is just the relative modular group Δ_{φ,ω}^{it}). Note the group law and strong continuity are actually *decorative*: the proof only uses V_tξ = ξ per t. On the Weyl side, k_{t+s} = k_t + u_tk_s holds identically (η − η_t + u_t(η − η_s) = η − η_{t+s}), and the chain rule imposes Θ_{t+s} = Θ_t + Θ_s − σ(k_t,u_tk_s)/2 — a constraint on Θ the refereed client formula must satisfy, but which the present proof never uses (see F).

## (C) Steps 3–4 — CORRECT

Conjugation: Γ(u_t)W(f)Γ(u_t)* = W(u_tf) with no phase; W(k)W(f)W(k)* = e^{−iσ(k,f)}W(f) (two half-phases σ(k,f)/2 + σ(k+f,−k)/2 = σ(k,f)); the scalar e^{iΘ_t} drops out of Ad. So φ(t,f) = −σ(k_t, u_tf); whether σ = Im⟨·,·⟩ or 2Im⟨·,·⟩ only rescales the free amplitude in Step 5 and is immaterial. WOT limit: ⟨W(g)Ω, W(f_t)W(h)Ω⟩ = e^{i(phases)}e^{−‖f_t+h−g‖²/4}; with f_t ⇀ 0 and ‖f_t‖ = ‖f‖, the exponent → ‖f‖² + ‖h−g‖² and the phases (all of the form Im⟨g or h, f_t⟩ plus t-independent terms) converge, giving e^{−‖f‖²/4}⟨W(g)Ω,W(h)Ω⟩; coherent vectors are total and ‖W(f_t)‖ = 1, so WOT follows. "Normality" is overkill — E is a vector state, so E(W(f_t)) → e^{−‖f‖²/4} is literally one matrix element. Bonus rigidity the submission missed: since E(W(f)) is t-independent and E(W(f_t)) → e^{−‖f‖²/4} ≠ 0, the phase e^{iφ(t,f)} converges *automatically* for every f.

## (D) Step 5 — CORRECT WITH REPAIR (the crux)

**(i) Mellin identification.** Once G1 (a.c. Lebesgue spectrum of the one-particle dilation, no point spectrum) is granted, the identification is just the spectral theorem: K ≅ L²(ℝ,dν;ℂ^m), u_t = e^{iνt}, K-inner product = plain L² — there is nothing extra to prove, and the multiplicity (2 or otherwise) is irrelevant: work in one component where ĥ ∉ L². G1 itself is standard for the interval standard subspace of the chiral current (dilations conjugate to translations in log coordinates on the two halves; cf. the modular-theory literature on standard subspaces, e.g. arXiv:2111.11266, arXiv:1703.06831). I accept G1 as cited; note it is load-bearing for Steps 4 and 5, not just Prop 1.

**(ii) Existence of η̂ (repair 1).** The cocycle identity k̂_{t+s} = k̂_t + e^{iνt}k̂_s forces k̂_t(ν) = ĥ(ν)(1−e^{iνt}) for a measurable ĥ (solve at two incommensurate times; k_t ∈ K makes ĥ ∈ L²_loc away from ν = 0). But the submitted claim "linear growth *forces* |η̂|² ~ (D/2π)ν⁻²" is **false as stated**: ‖k_t‖²/t → D is an averaged (Tauberian) statement and does not pin pointwise asymptotics of |ĥ|². **Repair**: nothing pointwise is needed. If ĥ ∈ L² near 0 then ‖k_t‖ ≤ 2‖ĥ‖ for all t, contradicting sup_t‖k_t‖ = ∞ (the refereed weaker fact, ⟺ Q ≠ 0). So ∫_{0<|ν|<ε₀}|ĥ|²dν = ∞, hence M(ε) := ‖ĥχ_{ε<|ν|<ε₀}‖² → ∞ as ε → 0. That is all the construction uses.

**(iii) Shell arithmetic (repair 2).** The submitted computation "∫_ε^{2ε}|η̂|²dν ~ D/2π constant per shell, so need N shells, ‖f_n‖ ~ N^{−1/2}" is **arithmetically wrong** for the ν⁻² density: ∫_ε^{2ε}(D/2π)ν⁻²dν = D/(4πε), divergent per shell. (The constant-per-shell picture is exactly right for a ν⁻¹ density — the log-growth case ‖k_t‖² ~ c log t — so the submission solved the wrong, harder case.) I ran the mandated numerics with model ĥ = e^{−ν}/ν (script created and deleted per policy in the session scratchpad): ‖k_t‖²/t → π·c confirming linearity; per-shell mass/(1/2ε) → 1.0000 (2^{−2} down to 2^{−18}), refuting "constant per shell"; single-shell test functions f̂_n = i(π/M)ĥχ_{[ε_n,2ε_n]} give ℓ(f_n) = π exactly with ‖f_n‖ = π/√M: numerically 1.21, 0.279, 0.069, 0.017, 4.3×10⁻³, 1.1×10⁻³ for ε_n = 2⁻⁴…2⁻²⁴ → 0. So a *single* shell suffices; the conclusion is strengthened, not broken.

**(iv) The load-bearing sign.** φ(t,f) = −Im⟨k_t, u_tf⟩ = Im⟨ĥ,f̂⟩ − Im⟨ĥ, e^{iνt}f̂⟩: the surviving term comes from the cross-cancellation (1−e^{iνt})‾·e^{iνt} = e^{iνt} − 1. Had the conjugation flow been u_{−t} relative to the cocycle's flow, both terms would be oscillatory and ℓ ≡ 0 — fatal. It is not: the chain rule c_{t+s} = c_tσ_t(c_s) that defines ĥ uses the *same* σ_t = Ad Δ^{it} that appears in V_tW(f)V_t*, so the flows coincide by construction. Verified. Riemann–Lebesgue applies since ĥ̄f̂_n ∝ |ĥ|²χ_S ∈ L¹ (S compact, away from 0); numerically φ(t,f_n) → π (3.127 at t = 10⁶ for ε = 2⁻¹², after non-monotone transients — convergence is slow but real). ℝ-linearity of ℓ and complex f (the factor i for phase alignment) are legitimate: K is a complex Hilbert space and W(f) is defined for all f ∈ K; "smoothness" of f̂ is unnecessary. Any σ-convention factor of 2 is absorbed into the free amplitude a; e^{±iπ} = −1 either way.

## (E) Step 6, sanity check, corollaries — CORRECT (with framing caveats)

**Step 6.** No exchange-of-limits fallacy: for each n the identity E(W(f_n)) = e^{iπ}e^{−‖f_n‖²/4} is exact (both t-limits in its derivation converge, per (C) and (D)); separately, ξ is *fixed*, ‖f_n‖ → 0 ⟹ W(f_n) → 1 strongly (‖(W(f)−1)W(g)Ω‖² = 2−2Re[e^{iθ}e^{−‖f‖²/4}], θ = O(‖f‖‖g‖), uniformly on coherent states), so E(W(f_n)) → 1 ≠ −1. No continuity of f ↦ E(W(f)) is invoked. Airtight.

**Sanity check.** Verified analytically and numerically: ĥ ∈ L² ⟹ ‖k_t‖² ≤ 4‖ĥ‖² (numerics: → 1.0, bound 2.0), M(ε) bounded, ℓ bounded, no contradiction; and Q = 0 with η ∈ K gives α = Ad W(η), W(η) ∈ A, so φ is in the orbit. Consistent.

**Corollaries.** (R1) verified: v = σ_{−T}(u) works since ω∘σ_{−T} = ω. (R2) verified: v = β⁻¹(u) for β ∈ Aut(A,ω). For "α ∉ Inn(A)·Mod(A)": on a III₁ factor σ^ψ_t = Ad((Dψ:Dω)_t)∘σ^ω_t with the cocycle in A, and the flow of weights is trivial, so Inn·Mod = Inn·{σ^ω_t}, and R1 suffices — fine, but this reduction should be stated. "Not pointwise inner" follows *directly* (ω itself is the failing normal state); the Isono framing needs care: Isono's Compositio 2024 paper (arXiv:2309.05279) *proves* Haagerup–Størmer (pointwise inner ⟹ Inn·Mod) for III₁ factors with trivial bicentralizer — which covers the hyperfinite III₁ factor here. So the honest statement is: α ∉ Inn·Mod (this theorem + R1), hence by Isono α cannot be pointwise inner, and (ω, φ) *exhibits explicitly* the witness state Isono's contrapositive only guarantees abstractly. That framing is correct; but the submission should not suggest Isono is needed — the witness is produced directly. "Orbit ⟺ Q = 0": the ⟹ direction is this theorem; ⟸ requires Q = 0 ⟹ η ∈ K, true for the smooth-profile BMT class assumed but not for arbitrary non-winding profiles with divergent H^{1/2} norm (for those, the same proof shows *non*-membership despite Q = 0). State the biconditional relative to the standing smoothness hypothesis, or restate it sharply as: orbit ⟺ sup_t‖k_t‖ < ∞ ⟺ ĥ ∈ L².

## (F) Scope — confirmed as claimed, and sharper

The proof needs only: (a) the cocycle has Weyl form e^{iΘ_t}W(k_t) with k̂_t = ĥ(1−e^{iνt}); (b) sup_t‖k_t‖ = ∞ (the G2 weak fact) — the linear law and the value D = Q²ℓ/2π are *never used*; even logarithmic growth ‖k_t‖² ~ c log t (ν⁻¹ density) kills orbit membership via the many-shell version the submission accidentally wrote down. Θ_t enters only inside Ad V_t and multiplies ξ-invariance as part of the genuine cocycle; no property of Θ beyond c_t being the true Connes cocycle is used. "D is the obstruction" is therefore an overstatement: D quantifies the obstruction; the obstruction itself is ĥ ∉ L².
