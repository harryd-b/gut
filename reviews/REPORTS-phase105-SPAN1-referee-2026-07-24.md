# Referee Report: S1 (anchoring of charged defects at fix(γ))

## S1-i — VERDICT: CORRECT

**Existence/support of P.** Write supp ρ ⊂ (a,b) ⊊ S¹. Define P(θ) = ∫_a^θ ρ. P is smooth (ρ smooth), vanishes on S¹∖(a,b): identically 0 left of supp ρ, and equal to Q = 0 right of it. So P is a smooth, compactly supported, single-valued function on S¹. It lies in the one-particle space (smooth ⇒ H^{1/2}-finite).

**Sign check.** With convention W(f)W(g) = e^{−iσ(f,g)/2}W(f+g), one computes Ad W(P)(W(f)) = e^{−iσ(P,f)}W(f). Now σ(P,f) = ∫P f′ dθ = −∫P′f dθ = −∫ρf dθ, integrating by parts **with no boundary term** because P is smooth and single-valued on the circle (this is exactly where Q = 0 is used — for Q ≠ 0 the "primitive" is not periodic and the integration by parts fails). Hence e^{−iσ(P,f)} = e^{+i∫ρf}, matching α_ρ. Under the opposite convention Ad W(P)(W(f)) = e^{+iσ(P,f)}W(f) one uses W(−P) instead; the conclusion (innerness by a local Weyl operator) is convention-independent. No sign fix affects the result.

**Locality.** A(J) for an interval J is generated by {W(f) : supp f ⊂ J} (standard for the U(1)-current net), and supp P ⊂ [a,b] ⊂ J for any open J ⊃ [a,b]. So W(P) ∈ A(J) genuinely. Then ω∘α_ρ = ω(W(P) · W(P)*), i.e., the defect state is unitarily conjugate to ω by a local Weyl unitary. One pedantic caveat: W(P) is defined up to the constant ambiguity in P; the compactly supported representative fixes it, and constants are in the kernel of σ anyway.

## S1-ii — VERDICT: CORRECT (with the multi-point refinement, which matters below)

If P is continuous on all of S¹ with P′ = ρ, then 0 = ∮P′ = Q, contradiction. So for Q ≠ 0 every profile implementing α_ρ pointwise must be discontinuous. Since P′ = ρ (smooth) away from the discontinuity set, on each complementary arc P is smooth and pinned up to a constant; hence the only possible discontinuities are **jumps** at finitely many chosen cut points (no wilder singularities can occur for smooth ρ), with heights summing (single-valuedness around S¹) to −Q, i.e., total jump magnitude Q up to orientation convention.

**Splitting:** yes, the jump may be distributed over any finite anchor set {x_i} with heights j_i, Σj_i = ±Q. This is a *choice*, not determined by ρ: two profiles for the same ρ differ by a piecewise-constant function. This freedom is essential for S1-iii: the correct statement there must be about *which anchor placements are admissible* and *which anchors carry charge visible to the coupling*, not about a unique anchor. Note also the two fixed points allow a legitimate split q₊ at ξ₊, q₋ at ξ₋ with q₊ + q₋ = Q. Later claims survive, but only in the re-scoped form below.

## S1-iii — VERDICT: WRONG as stated; a corrected, re-scoped version is CORRECT

**(a) Two-jump structure.** With ζ(x) = η(x) − η(γx): if η jumps by j at x₀, then η∘γ jumps at the point x with γx = x₀, i.e., at **γ⁻¹x₀** (the claim's first alternative is right; γx₀ is wrong). Since γ is an orientation-preserving diffeomorphism of S¹, the transported jump has the *same* height j, entering ζ with a minus sign. So ζ jumps by +j at x₀ and −j at γ⁻¹x₀. If x₀ ∉ fix(γ) these are distinct points; cancellation against other anchors is only partial: jump_ζ(y) = jump_η(y) − jump_η(γy), and full cancellation would force jump_η constant along the (infinite) γ-orbit, impossible for a finitely supported nonzero jump function. So a non-fixed anchor always leaves ζ with a genuine jump somewhere on its orbit. **At a fixed point x₀ = ξ±** the two jumps land at the *same* point with equal heights and cancel exactly, leaving ζ continuous there with ζ(ξ±) = 0 — this is precisely why fixed-point anchors are admissible.

**(b) The complementary-arc loophole — this kills the claim as stated.** γ fixes ξ± and preserves orientation, so it preserves *both* arcs: γ(I) = I and γ(I′) = I′. Hence the two jumps are always on the same side; the mixed case never occurs. If x₀ ∈ I′ (open complementary arc), then γ⁻¹x₀ ∈ I′, the entire surviving jump set of ζ (orbit points of anchors) lies in I′, and η is smooth on a neighborhood of Ī. Then ζ|_Ī is smooth, ζ(ξ±) = η(ξ±) − η(γξ±) = 0 automatically, and ζ_in = ζχ_Ī is a Lipschitz function with corners at ξ± only — H^{1/2}-finite (H¹ ⊂ H^{1/2}). **So a defect with all anchors in I′ is admissible by the stated finiteness criterion, with arbitrary Q ≠ 0.** S1-iii's conclusion "anchor set ⊂ fix(γ)" is refuted.

**(c) Both inside I.** Correct and consistent: x₀ ∈ I ⇒ γ⁻¹x₀ ∈ I (γ-invariance of I); by the telescoping argument in (a), at least one genuine jump of ζ survives at an orbit point in the *open* arc I, hence interior to Ī; a genuine jump interior to the truncation interval gives log-divergent H^{1/2} norm; ζ_in ∉ one-particle space; inadmissible. Orbit points accumulate only at ξ±, and the jump set is finite, so no endpoint-degeneracy escape.

**(d) Adjudication.** "Precisely fix(γ)" is wrong. The correct trichotomy for anchor placement:
- anchors in open I: **inadmissible** (interior jump, divergent);
- anchors at fix(γ) = {ξ±}: **admissible** (jumps cancel in ζ; kink-only truncation);
- anchors in open I′: **admissible**, but the profile is smooth on a neighborhood of Ī, so restricted to A(I) the defect is implemented by a smooth local profile — it is chargeless/vacuum-like from the I-side, and the coupling machinery never sees the charge.

**Strongest correct version of S1-iii:** *An admissible coupling excludes anchors from the open arc I. The charge visible to M_γ — the part of the defect that acts non-innerly relative to the I-side — must be anchored on fix(γ); charge anchored in I′ is admissible but invisible to (decoupled from) M_γ.* This is exactly the prompt's proposed rescue, and it is the version compatible with an invariant D = Q²ℓ/2π: the Q entering it must be the fix(γ)-anchored (coupling-visible) charge, possibly split q₊ + q₋ = Q between ξ₊ and ξ₋.

## S1-iv — VERDICT: GAP (geometry CORRECT; assembly logic overreaches)

**Geometry facts: all correct.** Cocompact ⇒ no parabolics; torsion-free ⇒ no elliptics; hence every nontrivial γ ∈ Γ is hyperbolic with two boundary fixed points and ℓ(γ) > 0. Conjugacy classes of nontrivial elements ↔ essential free homotopy classes, each containing a unique closed geodesic (negative curvature); contractible loops ↔ identity, no geodesic, no axis, no boundary fixed points.

**Logic problems.**
1. "Contractible ⟹ trivial stabilizer ⟹ no admissible anchor ⟹ Q = 0" is a non sequitur. For γ = e there is no axis, no arc I, no M_γ — the coupling machinery is undefined, so nothing about it forces Q = 0. A Q ≠ 0 defect exists regardless of Γ; it simply isn't coupled. What is true: a *chargeless smooth* defect is erasable by S1-i, and (standard) a Q ≠ 0 defect is never inner. The contractible branch says only "no coupling exists to localize charge," not "charge vanishes."
2. Given corrected S1-iii, the second half must read: *charge visible to M_γ* ⟹ anchored at fix(γ) ⟹ γ hyperbolic ⟹ essential class, ℓ(γ) defined. In that re-scoped form the implication chain is valid. Unqualified "charged admissible defects are anchored at fix(γ)" is false (I′ counterexample).
3. **Conflation confirmed.** The toy never defines a "defect loop"; γ is an algebraic *input* choosing which coupling to build. S1-iv does not derive that a defect selects a homotopy class — it shows that *for each chosen* hyperbolic γ, the M_γ-visible charge is pinned to fix(γ) and the pair (Q_visible, ℓ(γ)) is well-defined data of that chosen coupling.

**Strongest honest formulation:** *For each hyperbolic γ ∈ Γ (equivalently each essential free homotopy class, via its unique geodesic), the coupling M_γ admits charged defects only with the coupling-visible charge anchored on fix(γ), making (Q, ℓ(γ)) — hence D = Q²ℓ/2π — well-defined invariants of the coupled system. For the trivial class no coupling exists; chargeless smooth defects are locally erasable, and charged defects, while never inner, carry no γ-localized anchor. The toy characterizes where charge can live relative to a chosen γ, not which γ a defect "chooses."*

## Summary (5 lines)

1. **S1-i CORRECT**: Q = 0 gives smooth compactly supported P; sign works via boundary-term-free integration by parts; W(P) is genuinely local; α_ρ inner.
2. **S1-ii CORRECT**: Q ≠ 0 forces jump anchors, total jump Q, splittable over finitely many points — a freedom S1-iii must (and, corrected, does) accommodate.

Corrected version: *coupling-visible* charge is anchored on fix(γ); I′-anchored charge is invisible to M_γ.
4. **S1-iv GAP**: all hyperbolic-geometry facts check out, but "contractible ⟹ Q = 0" is a non sequitur (γ = e has no coupling at all), and the assembly conflates bulk "defect loops" with the algebraic input γ; re-scoped per-γ version is valid.
5. Net effect: the invariant D = Q²ℓ(γ)/2π survives, but only for the fix(γ)-anchored, coupling-visible charge of an explicitly chosen hyperbolic γ.
